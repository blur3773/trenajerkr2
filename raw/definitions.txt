History of Computers 
Abacus is an ancient counting tool invented in China around 1300 BC used to perform basic 
arithmetical operations such as addition, subtraction, multiplication, and division. 
The Analytical Engine is a mechanical computer designed in the 1830s by Charles Babbage. It is 
considered the first machine resembling modern computers because it contained an Arithmetic 
Logic Unit (ALU), control unit, memory, and an input/output system. 
Arithmetic Logic Unit (ALU) is a fundamental component of a computer's processor responsible 
for performing mathematical calculations and logical operations. 
Integrated Circuit (IC), often referred to as a microchip, is a miniature electronic circuit consisting 
of various interconnected components fabricated onto a single semiconductor substance.  
Moore’s Law is a theory based on a prediction made by Gordon Moore in 1965 stating that 
computer processing power doubles approximately every two years as manufacturing improves and 
more transistors are placed on a circuit. 
The Pascaline is the first mechanical adding machine, built by Blaise Pascal between 1642 and 
1644, capable of performing addition and subtraction. The device was basically a wooden box with 
a number of gears and wheels.  
Parallel processing is a computing method where multiple processors or cores perform several 
calculations or execute processes simultaneously.  
Semiconductor is a material, such as silicon, whose ability to conduct electricity increases as its 
temperature rises. 
Transistor is a semiconductor that controls voltage or current flow in electronic signals acting as a 
switch. This small electronic component replaced vacuum tubes in second-generation computers, 
leading to higher speeds and smaller computer sizes. 
Vacuum tube is an electronic device that regulates electron movement in a vacuum. It was an early 
electronic component used in first-generation computers (1940s) to control the flow of electricity. 
The first-generation computers are electronic digital computers (1940s) characterized by the use 
of vacuum tubes, enormous physical size, high electricity consumption, and the ability to solve only 
one problem at a time. 
The second-generation computers are computers (late 1950s–early 1960s) which utilized 
transistors instead of vacuum tubes. Consequently, these machines were ten times faster, smaller in 
size, and required less maintenance. 
The third-generation computers are computers (1965–1972) built with integrated circuits, 
enabling speeds of a million calculations per second and significantly lower production and 
maintenance costs. 
The fourth-generation computers are computers (mid-1970s–present) based on thousands of 
circuits placed on a single microprocessor chip, supporting Graphical User Interfaces (GUI) and 
network connectivity. 
The fifth-generation computers are modern computers based on parallel processing and Artificial 
Intelligence, designed to simulate human reasoning and respond to natural language input. 
 
Types of Computers 
Desktop PC is a personal computer designed for use in a single, stationary location, typically 
consisting of a system unit, monitor, keyboard, and mouse. 
Laptop is a portable, lightweight computer with a hinged design, featuring a flat LCD screen, a 
built-in keyboard with a touchpad, and a battery for mobile use. 
Mainframe is a large, powerful computer capable of supporting multiple users and thousands of 
simultaneous queries; it is often used for large-scale data processing in banks and big corporations. 
Netbook is a mobile computer that is typically smaller than a laptop. They were popular for basic 
web browsing and often had fewer functions than a full-sized laptop. 
Server is a central computer connected to a network of "client" workstations, designed to store data 
and provide services with higher processing power and memory than a standard workstation. 
Supercomputer is the fastest type of computer, containing tens of thousands of processors for 
simultaneous execution of data-intensive tasks such as weather forecasting and aerodynamics. 
Tablet PC is a highly portable mobile device with a touch screen interface, typically lacking a 
physical keyboard and using a mobile operating system. 
Touchpad is a sensitive pad built into a laptop keyboard that allows the user to move the pointer on 
the screen by touch, serving as a replacement for a mouse. 
 
Computer Hardware 
Arithmetic Logic Unit (ALU) is the specific part of the CPU that performs actual arithmetic (e.g., 
addition, subtraction) and logical operations (e.g., AND, OR, NOT). 
BIOS (Basic Input/Output System) is a ROM chip on the motherboard containing firmware used 
to perform hardware initialization during the booting process. 
Bus is an electrical channel that carries signals and allows devices inside the computer to 
communicate with each other. 
Central Processing Unit (CPU) is the "brain" of the computer, built into a single chip 
(microprocessor), responsible for executing program instructions and coordinating all other units. 
Clock speed is the measurement of how many cycles a CPU executes per second, typically 
measured in gigahertz (GHz). 
Control Unit is the component of the CPU that interprets instructions from the user's program and 
directs the rest of the hardware to execute them. 
Expansion slot is a socket on the motherboard that allows users to install expansion cards to add 
features like sound or network capabilities. 
Hardware is any physical, electronic, or mechanical part of a computer system that can be seen or 
touched. 
Input device is a hardware unit that enables the user to enter data into the computer's memory, such 
as a keyboard, mouse, or scanner. 
Motherboard is the main circuit board of a computer that holds the CPU, memory chips, expansion 
slots, and controllers for peripherals. 
Mouse is small input device used to specify the position of the cursor or to make choices from 
menus.  
Output device is any peripheral that allows the user to extract or view the finished results from the 
system, such as a monitor or printer. 
Peripherals are physical units attached to the computer, including input, output, and storage 
devices. 
Program counter (PC) is a CPU register that keeps track of the next instruction to be performed. 
Instruction register (IR) is a CPU register that holds the instruction that is being executed now. 
RAM (Random Access Memory) is volatile main memory used to temporarily store data and 
instructions while they are being processed by the CPU; its contents are lost when power is turned 
off. 
Registers are high-speed memory units within the CPU used to store and control data immediately 
needed for instruction execution.  
ROM (Read Only Memory) is non-volatile memory containing permanent instructions and 
routines for basic CPU operations, such as the BIOS. 
Scanner is an input device that converts images, printed text or handwriting into a digital image.  
Speaker is a device that provides sound output.  
Storage device is a peripheral device used for permanent or long-term storage of data and 
programs, such as hard drives or flash drives. 
SMT (simultaneous multi-threading technology) is a technology that allows two threads to run 
on a single core, which enables more effective use of CPU resources and improves overall 
performance. 
 
Primary memory 
Cache hit is a situation when the processor finds data in the cache area. 
Cache memory is a type of very fast volatile memory that holds a small amount of recently 
accessed data and acts as a buffer between the main memory and the processor. 
Cache miss is a situation when the processor does not find data in the cache area and reads it in the 
slower RAM.  
RAM is a type of volatile memory inside a computer that stores data temporarily and gets erased 
when the computer is turned off. 
ROM is a type of non-volatile memory including BIOS, firmware, bootloaders that store critical 
instructions to initiate the system. 
Primary memory is an internal storage device, such as cache or RAM, which can be directly 
accessed by the CPU with minimum or no delay. 
Write-back cache is a method changing data in the cache area first, while RAM is updated later. 
Write-through cache is a method of refreshing data in the cache and main memory simultaneously. 
 
Secondary storage 
Access time is the amount of time it takes for a storage device to search and locate the data you 
plan to open, copy, move. 
Capacity is the maximum amount of data a storage device can contain. 
CD-R is a type of CD which is released blank and can be recorded on once only. 
CD-ROM is a type of CD which comes pre-recorded and doesn't allow to change data stored on it. 
CD-RW is a type of CD whose data can be written, read, erased, and rewritten. 
Flash memory is a type of non-volatile memory which works by using electronic circuits to store 
and retrieve data. 
Floppy disk is an outdated storage device of low capacity made of flexible plastic material upon 
which data is stored on magnetic tracks. 
Magnetic storage is a type of storage in which data is written by magnetizing particles on a disk or 
tape. 
NOR flash is a type of flash memory that provides fast access to small amounts of data used in 
bootloaders and firmware.  
NAND flash is a type of flash memory that provides slow access to large amounts of data used in 
SSDs and USB flash drives. 
Optical storage is a type of storage is which data is written as a series of reflective marks and read 
with a laser. 
Read/write head is a part of an HDD which reads and writes data by magnetizing and 
demagnetizing fields on spinning platters. 
Transfer rate is the average speed at which data can be transmitted from one device to another, 
often measured in megabytes per second. 
 
 Software 
CLI is the way to interact with a computer system through typing various commands in the form of 
lines of text. 
Compatible means being able to work with another device or program. 
Device driver is a type of software that controls specific hardware of the computer system. 
Firmware permanent software or set of instructions stored in ROM of the computer system. 
GUI is a user-friendly interface based on graphics; it uses a WIMP environment. 
Operating system is a set of programs that manage the computer's hardware resources, establish a 
user interface, and provide the environment for application programs to run. 
Open-source software is a type of computer software whose copyright holder grants users the 
rights to use, study, change, and distribute the software to anyone and for any purpose. 
Proprietary software is non-free software whose users are not allowed to share, modify it, and 
distribute the modifications. 
Spreadsheet is a computer application for organization, analysis and storage of data in a tabular 
form. 
Word processor is a computer application used to compose and edit texts. 
Preemptive multitasking is a type of multitasking where the operating system can initiate a 
context switch to satisfy the scheduling policy's priority, thus preempting the active task. 
Cooperative multitasking is a computer multitasking technique in which the operating system 
never initiates a context switch from a running process to another process. 
 
Networks  
Topology is the configuration of the elements (nodes) of a network. 
Local area network (LAN) is a collection of devices connected together in one physical location, 
such as a building, office, or home. 
Metropolitan Area Network (MAN) is a high-speed network that interconnects multiple LANs 
(local area networks) within a specific geographic area, such as a city, large campus, or 
municipality. 
Wide Area Network (WAN) is a type of computer network that connects computers and other 
devices over a large geographical area (a country or a continent). 
Network hub is a node that broadcasts data to every computer or Ethernet-based device connected 
to it without restriction.  
Network switch is identical to a network hub, but unlike a hub, a switch forwards data to the 
specific device only based on its MAC address. 
Bus topology is a network setup where all nodes (computers, servers, printers) connect directly to a 
single, central cable, known as the backbone or bus. 
Peer-to-peer network is a network architecture in which all the computers have the same 
capabilities, i.e. share files and peripherals, without requiring a separate server computer. 
Client-server network is a computing model in which multiple clients connect to a central server 
to access resources, such as files, applications, and data. 
Ring topology is a LAN topology, in which all devices are interconnected in a continuous loop. 
Tree topology is a type of network setup that combines elements from both star and bus topologies 
to create a hierarchical structure.  
Mesh topology is a network configuration where every device is interconnected with every other 
device, providing multiple routes for data to travel.  
Hybrid topology is a network structure that combines two or more different types of topologies 
into a single system. 
Star topology is a LAN topology, in which all data flows through a central hub, a common 
connection point for the devices on the network. 
Ad hoc topology is a wireless peer-to-peer network that does not rely on the existing infrastructure.  
Bridge is a hardware component connecting networks that use the same protocol. 
Router is a networking device that can send data packets from one network to another. 
Gateway is a device or software used to enable communication between two networks that may be 
using different protocols. 
Computer network is a group of computers that use a set of common communication protocols 
over digital interconnections for the purpose of sharing resources located on or provided by the 
network nodes. 
Latency is the time delay between a user's action (request) and the system's response, typically 
measured in milliseconds (ms). 
Modem (modulator-demodulator), is a computer hardware device that converts data from a digital 
format into a format suitable for an analog transmission medium such as telephone or radio. 
Wired networks are communication systems that connect devices (computers, printers, servers) 
using physical cables, such as Ethernet (twisted pair), fiber optics, or coaxial cables, to a central 
router or switch. 
Wireless network is a computer network that uses wireless data connections between network 
nodes. 
Wireless LAN (WLAN) is a wireless computer network that forms a local area network by linking 
devices over Wi-Fi radio signals. 
Backbone network is a high-capacity communications network that serves as the principal data 
path interconnecting multiple subnetworks. 
The OSI (Open Systems Interconnection) model is a set of rules that explains how different 
computer systems communicate over a network. 
The application layer is the layer that serves as the interface between the end-user applications and 
the underlying network services. 
The presentation layer is the layer that acts as a translator and negotiator, ensuring that data from 
the application layer (Layer 7) can be understood by the receiving system. 
The session layer of the OSI model is the layer that manages the establishment, maintenance, and 
termination of connections (sessions) between applications on different devices. 
The transport layer of the OSI model is the layer that ensures reliable, ordered, and error-checked 
delivery of data between applications on different network hosts. 
The network layer is the layer that handles routing, forwarding, and logical addressing (IP 
addresses) to send data packets between different networks or devices. 
The data link layer is the OSI model layer responsible for node-to-node data transfer on a local 
network segment, ensuring reliable, error-free transmission between directly connected devices. 
The physical layer is the lowest layer of the OSI model and it is responsible for transmitting raw 
bits of data from one node to the other over physical cable or wireless connection. 
Media Access Control (MAC) address is a 12-digit hexadecimal number that uniquely identifies 
every device connected to a network. 
Internet Protocol (IP) address is the unique identifying number assigned to every device 
connected to the internet. 
Bluetooth is a wireless technology that allows mobile devices and other peripheral devices to 
communicate over short distances. 
 
The Internet 
Coaxial cable is a type of cable that consists of four main components: inner conductor, insulation, 
metal shield, and jacket.   
Virtual circuit switching is an approach in which a path is built between the source and the 
destination points through which all packets are routed.  
Datagram switching is a packet switching method that treats each packet, or datagram, as a 
separate entity. Each packet is routed via the network on its own though different paths, and then the 
packets are reassembled at the destination point.  
Digital Subscriber Line is a broadband communication technology designed for the use on 
telephone lines; it allows a single phone connection to be used for both Internet service and voice 
calls at the same time. 
Fiber-optic technology is the fastest wired way to access the Internet transmitting information as 
pulses of light through strands of fiber made of glass or plastic over long distances. 
Bandwidth is the measure of how much information can pass through a data connection in a given 
amount of time, measured in bits per second.  
Cellular network is a radio-based communication network distributed over land areas called cells, 
each served by a fixed-location transceiver, known as a cell tower.  
Dial-up connection is the least expensive but also the slowest way to access the Internet which 
uses a standard phone line and analog modem. This technology pre-existed the DSL connection and 
used one and the same frequency to transmit voice and data signal.  
The TCP/IP stack is a four-layer protocol model used on the Internet to govern how data is 
transmitted between computers. It is named after the two main protocols TCP and IP and is widely 
used as a framework to model communication in a network. 
The World Wide Web (WWW) is an information system accessible through the Internet where 
documents and other web resources are identified by a Uniform Resource Locator (URL). 
 
Search Engines  
 
Ranking is the process of ordering the search results from most relevant to least relevant.  
Web crawler is a special program also known as a spider that regularly browses the web to 
discover new content. It works by following hyperlinks from page to page and storing copies of the 
pages in a search engine's index. 
Human-powered directories are systems that depend on human editors for their listings. A 
directory gets its information from submissions, which include a short description to the directory 
for the entire site, or from editors who write one for sites they review. When a user query is entered, 
the system looks for matches only in the descriptions submitted. 
Meta-search engine is a type of search engine which does not have a database of indexed pages of 
its own. Instead, it sends users’ queries to several other search engines and compiles top results 
from each into one overall list. 
Search bar is a field on the screen that allows users to enter keywords or phrases to find specific 
content.  
Web browser is software that serves as a gateway to the World Wide Web. It identifies individual 
URLs and displays the corresponding page on the user’s device.  
Search engine is software system that scans, indexes, and retrieves web content to help users find 
information online.  
Hyperlink is a highlighted word or image in a hypertext document that takes a user to another 
location when he/she clicks on it. 
 
Web design 
Backend development is a field of web development that is associated with the part of the site 
connected to the server. 
Frontend development is a field of web development that focuses on the visible part of the site. 
HTML is a code used to describe the structure of information on a webpage telling the web 
browser how to display its content. 
Hyperlink is a text, image or button that takes you to other web pages when you click on it. 
Java Script is a programming language used by web developers to create dynamically updating 
content, use animations, pop-up menus, clickable buttons, etc. 
CSS is a mechanism for adding style (e.g. fonts, colors, spacing) to web documents. 
SEO is a set of improvements that increases visibility of a site and helps it rank higher on the 
results page. 
Website builder is a platform that can be used to create a website without having to code. 
 
Programming languages 
Assembly language is a low-level programming language that uses symbolic instructions rather 
than raw binary coding to communicate directly with a computer's hardware, 
Object-oriented programming (OOP) is a programming paradigm in computer science that relies 
on the concept of classes and objects. Objects are defined as software entities that encapsulate data 
and functions.  
Compiler is a special program that converts a source program (written in a high-level language) 
into object code in one go. 
Interpreter is a special program that translates the source code line by line, as the program is running. 
Inheritance is the ability of one class to use properties and behavior of another class. 
Polymorphism is a programming language's ability to process objects differently depending on 
their data type or class.  
Encapsulation is a fundamental concept that combines data (attributes) and methods (functions) 
into a single unit. 
Source code is a set of instructions typically written in a high-level programming language that 
defines how a program or application should function. 
Machine code is a code made of just two numbers (0 and 1). 
Debugging is the technique of detecting and correcting errors which may occur in programs. 
 
 
Malware and cybercrime 
Spyware is malicious software designed to enter a computer device, gather data about a person or 
organization and forward it to a third party without a user’s consent.  
Adware is a form of financially supported malware that usually presents itself as unwanted 
commercials. 
Keylogger is a type of spyware used to monitor and record each keystroke on a specific keyboard. 
The information is gathered and sent to the attacker. This malware is most often used for stealing 
passwords.  
Worm is a standalone malicious computer program that replicates itself to infect other computers. It 
is able to spread across the network directly without attaching itself to a host file. 
Hijacking is a type of cybercrime which involves redirecting anyone trying to visit a certain site 
elsewhere. 
DDoS attack is an attack where hackers overload networks and servers with traffic so that 
computer systems are unable to keep up with legitimate needs. 
Trojan is a type of malware that misleads users of its true intent by pretending to be a useful 
program. 
Phishing is a type of cybercrime where the attacker sends a fake message designed to trick a person 
into revealing sensitive information to the attacker. 
Ransomware is a type of malware that threatens to publish the victim’s data, encrypts the victim’s 
data or blocks access to the device unless a payment is made.  
Miner is a virus which uses your computer power to earn cryptocurrency for others. 
Piracy is unauthorized copying of a program for sale or distributing to other users. 
Backdoor is a technique that involves leaving, within a completed program, an illicit program that 
allows unauthorized and unknown entry. 
Defacement is a cybercrime which involves changing the information shown on another person's 
website. 
Salami shaving is a computer crime in which a program is altered so that it transfers a small amount 
of money from a large number of accounts to make a large profit. 
Misdirection routine is the component that allows a virus to hide itself.  
Trigger is the component of a virus that activates payload. 
Payload is the component of a virus that does the damage to the computer system.  
Reproduction routine  is the component that allows the virus to self -replicate and infect other 
programs. 
 
 
Data security 
Firewall is a combination of software and hardware used to protect private networks by filtering 
incoming data traffic. 
Signature is a distinguishing feature that every computer virus contains. 
Heuristic scanning is a type of malware detection technique which allows identifying potentially 
malicious software without having an exact match in signature database. 
Cybersecurity is the practice employed to protect and secure computers, servers, networks, mobile 
devices, electronic systems, and data from being attacked. 
Multi-factor authentication (MFA) is a user verification technology that requires more than one 
type of user validation.  
Encryption is a way of encoding data so that only authorized parties can understand the 
information. 
Brute force is a cybersecurity threat where a hacker attempts to access a system by systematically 
testing different passwords. 
Password is secret data, typically a string of characters, usually used to confirm a user's identity.  
Cryptanalysis is a method of spotting a weakness in the cipher aiming to decrypt encoded data.  
Secure Sockets Layer (SSL) is an Internet security protocol that encrypts data to ensure secure 
communication between devices over a network. 
Web application firewall (WAF) helps protect web applications by filtering and monitoring HTTP 
traffic between a web application and the Internet. 
Ciphertext is encrypted text transformed from plaintext using an encryption algorithm. 
Cryptography is the process of hiding or coding information so that only the person a message was 
intended for can read it. 
Cryptographic key is a randomized string of bits used to encrypt and/or decrypt data 
Symmetric encryption is the process of using a single key to both encrypt and decrypt data. 
Asymmetric encryption (or public-key cryptography) is a security method that uses a 
mathematically linked pair of keys—a public key for encryption and a private key for decryption—
to protect data. 
Antivirus software is designed to detect, present and take action to disarm or remove malicious 
software from your computer such as viruses, worms and Trojan horses. 
Packet filtering firewall is a network security device that filters incoming and outgoing network 
packets based on a predefined set of rules. 
Backup program is a program that stores a copy of data on a storage device to keep it safe. 
Incremental backup is a backup type that only copies data that has been changed or created since 
the previous full, differential or incremental backup.  
Differential backup is a data protection method that copies all files changed since the last full 
backup. 
 
The future of IT 
Artificial Intelligence (AI) is a technology that simulates human intelligence in computer systems. 
It enables a computer or a robot controlled by a computer to do tasks that are usually done by 
humans. 
The Internet of Things (IoT) is a system of interrelated computing devices, mechanical, and 
digital machines provided with the ability to share data in order to automate processes. 
Virtual Reality (VR) is a computer-generated space in which the user interacts with artificial 
objects through 3-D computer simulation. 
Neural Networks (NN) is computing systems with interconnected nodes that resemble neurons in 
the human brain. Using algorithms, they can recognize hidden patterns and correlations in raw data, 
classify it, and continuously learn and improve. 
Augmented Reality (AR) is an enhanced version of the real physical world, which integrates 
digital information with the existing environment in real time. 
Backpropagation is an algorithm that is designed to test for errors working back from output nodes 
to input nodes. 
Unique Identifier (UID) is a numeric or alphanumeric string assigned to a specific entity—such as 
a user, device, file, or database record—to distinguish it from others within a system. 
Machine Learning (ML) is a subset of AI that enables software to learn from data, identifying 
patterns to make predictions or decisions without being explicitly programmed. 
Artificial neurons are units arranged in a series of layers, each of which connects to the layers on 
either side. 
Input units are the layers of artificial neurons designed to receive various forms of information 
from the outside world that the network will attempt to learn about, recognize, or otherwise process. 
Output units are the layers of artificial neurons designed to signal how the network responds to the 
information it has learned. 
Hidden units are the layers of artificial neurons between the input and output layers that process 
information and form the core computational engine, or "artificial brain," of a neural network. 
Weight is a numerical value representing the strength of the connection between two units 
(neurons) in a neural network, where a positive value indicates excitation and a negative value 
indicates inhibition. 
Human-level artificial intelligence (HLAI) is a term used to describe artificial intelligence 
systems that have human-like abilities in terms of reasoning, learning, perception, and problem 
solving. 
Turing Test is a test of whether a computer can show intelligent behavior like that of a human, done 
by seeing if a tester can tell whether the answers to a set of questions come from the computer or 
from a person.
