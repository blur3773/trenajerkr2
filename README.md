# Тренажер к КМ2 (оффлайн)

## Как запустить
1. Открой файл `/Users/maxizosimov/Desktop/тренажер по англу/index.html` в браузере.
2. Интернет не нужен: все данные лежат локально в `data.js`.

## Что внутри
- `Тренировка`: отдельная практика по разделам.
- `Пробный КМ2`: формат 25 + 10 + 6 вопросов, как в описании контрольной.
- `Словарь`: просмотр всех терминов, аббревиатур и определений с поиском.
- Таймер, прогресс, итоговая статистика по блокам.

## Если PDF обновятся
1. Заменить PDF в `Downloads` (или поправить пути в `build_data.py`).
2. Выполнить:
   ```bash
   python3 /Users/maxizosimov/Desktop/тренажер\ по\ англу/build_data.py
   ```
3. Перезапустить `index.html`.
