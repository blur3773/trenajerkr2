# Тренажер к КМ2 по английскому (оффлайн)

Работает без интернета. Подойдет для подготовки к формату:
- перевод терминов;
- расшифровка аббревиатур;
- определения терминов.

## Быстрый старт (30 секунд)
1. На GitHub нажмите `Code` → `Download ZIP`.
2. Распакуйте архив в любую папку.
3. Откройте файл `index.html` в любом браузере (двойной клик).
4. Готово: можно сразу тренироваться.

Ничего устанавливать не нужно: тренажер полностью оффлайн и работает прямо из распакованной папки.

Важно: абсолютный путь не нужен. Не надо запускать через `/Users/.../index.html`, достаточно открыть `index.html` внутри папки проекта.

## Телефон (как приложение на экране)
Рекомендуемый вариант: открыть тренажер по ссылке GitHub Pages и установить на экран.

### 1) Включить GitHub Pages (делается один раз)
1. Открой репозиторий на GitHub.
2. `Settings` → `Pages`.
3. В `Build and deployment` выбери:
- `Source`: `Deploy from a branch`
- `Branch`: `main` и папка `/ (root)`
4. Нажми `Save`.
5. Подожди 1-2 минуты, появится ссылка вида: `https://blur3773.github.io/trenajerkr2/`

### 2) Установить на Android
1. Открой ссылку Pages в Chrome.
2. Нажми меню браузера → `Добавить на главный экран` / `Install app`.
3. После установки тренажер запускается как обычное приложение.

### 3) Установить на iPhone (Safari)
1. Открой ссылку Pages в Safari.
2. Нажми `Поделиться` → `На экран «Домой»`.
3. Подтверди добавление.

Важно:
- Для установки на экран нужен именно `https`-адрес (GitHub Pages), а не локальный `file://`.
- После первого открытия тренажер кэшируется и может работать оффлайн.

## Что есть в приложении
- `Тренировка` — гибкая практика по разделам.
- `Пробный КМ2` — режим 25 + 10 + 6 вопросов.
- `Словарь` — все термины, аббревиатуры и определения с поиском.
- Таймер, прогресс и итоговая статистика.

## Если не открывается двойным кликом
Откройте терминал в папке проекта и выполните:

```bash
python3 -m http.server 8000
```

Потом откройте в браузере:
[http://localhost:8000](http://localhost:8000)

## Как обновить базу из своих PDF
Это нужно только если вы хотите пересобрать `data.js` из новых файлов.

1. Создайте папку `source_pdfs` рядом с `build_data.py`.
2. Положите туда 3 PDF (в названии должны быть слова):
- `перевод`
- `определения`
- `аббревиатуры`
3. Запустите:

```bash
python3 build_data.py
```

Скрипт сам найдет PDF. Если каких-то файлов нет, он покажет, что именно добавить.
